# Silit
> Silit is a simple catalog for books, comic books, and graphic novels that maps out franchise timelines according to their internal in-universe chronological order.

## Features
- **Media Catalog:** Browse and organize literary works and comic books.
- **Chronological Timelines:** View stories in their actual in-universe order, not just by publication date.
- **Franchise Tracking:** Easily follow complex, multi-series storylines.

---

## Tech Stack
- Frontend: React / TypeScript
- Backend: JSON-Server
- Database: PostgreSQL

---

## Getting Started
1. Clone de repository:
git clone https://github.com/BernardoPaiva412/silit.git

2. Install dependencies:
npm i

3. Run the development server:
npm run dev
